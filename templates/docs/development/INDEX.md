## Status Guide

- 🔴 **Not Started** - Planned but not begun
- 🟡 **In Progress** - Active work
- 🟢 **Ready** - Implementation complete, ready for `/close-dev`
- ⚫ **Blocked** - Waiting on external dependency

## Phases

- **Planning** - Requirements gathering
- **Design** - Architecture/API design
- **Implementation** - Active coding
- **Testing** - Test coverage
- **Review** - Code review/final checks

---

**Commands:**
- `/init-dev {feature}` - Create development plan (`--refresh` to update)
- `/close-dev {feature}` - Complete and archive
